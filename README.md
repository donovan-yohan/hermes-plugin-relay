# hermes-plugin-relay

Hermes-native external-agent participants for Hermes Desktop.

The Relay IDE runtime is **not** a dependency. The project borrows the useful adapter/event-normalization shape, then implements Claude Code, Codex, Pi, Prime Agent, and future adapters inside the plugin.

Current artifact:

- [`docs/spikes/hermes-desktop-relay-agent-mentions.md`](docs/spikes/hermes-desktop-relay-agent-mentions.md) — participant model, plugin/runtime architecture, required Hermes transcript seam, trust boundary, and implementation slices.

Status: architecture spike. No runtime plugin has been enabled yet.
